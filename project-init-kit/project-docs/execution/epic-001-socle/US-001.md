## En tant que candidat

Afin de savoir quelles formations sont ouvertes à l'inscription avant de décider de postuler.

## Contexte

La structure backend `backend/` existe déjà (US-003). Il faut maintenant :
- Créer la table `cursus`
- Créer l'entité `Cursus` dans `entities/`
- Créer l'endpoint `GET /api/v1/cursus` dans `api/v1/`
- Créer la page d'accueil frontend qui appelle cet endpoint et affiche la liste

Les données de cursus sont **réelles** (issues du dossier officiel `cursus/` : MPC, Génie Civil, Génie Électronique, Génie Électromécanique, Architecture).
