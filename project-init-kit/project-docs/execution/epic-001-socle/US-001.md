# US-001 — Consulter la liste des cursus depuis l'accueil

## En tant que candidat
Je veux voir la liste des cursus disponibles à la FDS-UEH depuis la page d'accueil du portail
Afin de savoir quelles formations sont ouvertes à l'inscription avant de décider de postuler.

## Contexte

La structure backend `backend/` existe déjà (US-003). Il faut maintenant :
- Créer la table `cursus` (ou utiliser une table initiale si elle s'appelle différemment — à confirmer avec le schéma §9.3 du cahier des charges)
- Créer l'entité `Cursus` dans `entities/`
- Créer l'endpoint `GET /api/v1/cursus` dans `api/v1/`
- Créer la page d'accueil frontend qui appelle cet endpoint et affiche la liste

Les données de cursus sont **réelles** (en base via seed), pas hardcodées dans le frontend.

Ce qu'il ne faut pas supposer déjà fait : aucune couche métier n'existe encore — tout est à créer dans cette story.

## Critères d'acceptation

- [ ] `GET /api/v1/cursus` retourne un tableau JSON d'au moins 2 cursus avec : `id`, `nom`, `description_courte`, `date_ouverture_inscription`, `date_fermeture_inscription`
- [ ] La page d'accueil (`/`) affiche la liste des cursus avec leur nom et dates clés
- [ ] Les données viennent de PostgreSQL (local) — pas de données hardcodées dans le code
- [ ] Un script `seed_db.py` (ou équivalent) insère au moins 2 cursus en base au lancement
- [ ] `pytest tests/` passe toujours en vert (aucune violation architecture introduite)

## Hors périmètre

- Fiche détaillée d'un cursus — c'est US-002
- Filtrage ou recherche de cursus — post-MVP
- Design final de la page — la page doit être fonctionnelle, le polissage visuel viendra après
- Déploiement Railway/Vercel — US-004
