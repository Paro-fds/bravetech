# US-015: Export CSV/PDF filtré des dossiers validés

**Status:** 🔲 Backlog  
**Milestone:** Epic 4 — Could Have & Should Have  
**GitHub Issue:** [#15](https://github.com/Paro-fds/bravetech/issues/15)

**Priorité MoSCoW:** 🔵 Could Have

---

## En tant qu'administrateur FDS
Je veux pouvoir exporter la liste des dossiers validés au format CSV ou PDF  
Afin de la transmettre aux commissions d'admission qui travaillent hors ligne.

## Critères d'acceptation
- [ ] L'endpoint `GET /api/v1/admin/candidatures/export?format=csv&statut=valide` retourne un fichier CSV téléchargeable avec les colonnes : `reference_dossier`, `nom`, `prenom`, `deplacement_physique`, `created_at`.
- [ ] L'endpoint `GET /api/v1/admin/candidatures/export?format=pdf` retourne un PDF formaté avec la même liste.
- [ ] Le filtre `statut` est optionnel — sans filtre, tous les dossiers sont exportés.
- [ ] Ces endpoints sont protégés par le JWT admin (401/403 sinon).
- [ ] Un bouton « Exporter CSV » et « Exporter PDF » est visible sur le dashboard admin.

## Hors périmètre
- Export des documents eux-mêmes (fichiers uploadés).
- Rapport statistique avancé (post-MVP).

## Tâches
- [x] Implémenter l'export CSV avec la stdlib Python `csv`
- [x] Choisir et intégrer la lib PDF : **reportlab** (voir notes)
- [x] Ajouter l'endpoint d'export dans le router admin
- [x] Ajouter les boutons d'export sur le dashboard React

## Définition de fini
- [ ] Un admin authentifié peut télécharger un CSV ou PDF listant les dossiers filtrés par statut.

## As-built notes
**2026-11-01 — code écrit et vérifié sur un vrai serveur ; boutons vus à l'écran ; mise en page du PDF non vue** (branche `feat/us-015-export`, empilée sur US-021) :
- **Route** : `GET /api/v1/admin/candidatures/export?format=csv|pdf` (CSV par défaut), protégée par le routeur `/admin` (401 sans jeton). Elle est déclarée **avant** `/candidatures/{reference}`, sinon « export » serait lu comme une référence (testé). Réponse en pièce jointe (`candidatures-AAAA-MM-JJ.csv|pdf`), `Cache-Control: private, no-store`.
- **Filtres** : les mêmes que le tableau de bord (`statut` = `en_examen`, `action_requise` ou `complet`, `q`, `deplacement_physique`), et **sans pagination** : l'export contient tous les dossiers correspondants. Sans filtre, tous les dossiers soumis sont exportés. La valeur `statut=valide` de la story n'existe pas côté dossier ; « dossiers validés » correspond à `statut=complet` (les 5 pièces validées). Les brouillons ne sont jamais exportés.
- **Colonnes** : `reference_dossier`, `nom`, `prenom`, `deplacement_physique` (Oui / Non), `statut` (libellé), `pieces_validees` (« 3/5 »), `soumise_le` (UTC, `Z`). Par rapport à la story : `soumise_le` remplace `created_at` (la date qui compte pour un dossier est celle de la soumission) et deux colonnes s'ajoutent (statut, pièces validées). **Ni email, ni téléphone, ni adresse** : l'export circule hors de la plateforme, on n'y met que le nécessaire.
- **CSV pour Excel en français** : séparateur « ; », BOM UTF-8 (les accents s'affichent), fins de ligne CRLF. **Injection de formule neutralisée** : un nom ou un prénom commençant par `=`, `+`, `-` ou `@` (saisie d'un candidat) est précédé d'une apostrophe (testé avec `=HYPERLINK(...)`).
- **PDF : reportlab** retenu plutôt que weasyprint : bibliothèque Python pure, installation simple (wheel précompilé pour `python:3.11-slim`, aucune bibliothèque système à ajouter à l'image Docker), alors que weasyprint exige des bibliothèques système. Contrepartie : mise en page « tableau » sobre, pas de HTML/CSS. PDF paysage A4, titre, rappel des filtres, nombre de dossiers, date de génération (UTC), en-tête de tableau répété à chaque page, pied de page « document confidentiel ». Polices PDF standard : le français et le créole passent ; un caractère hors de ce jeu (alphabet non latin) s'affiche en carré sans faire échouer l'export. La saisie est échappée (un prénom `<b>x</b> & Co` ne casse pas le PDF).
- **Trace** : chaque export est journalisé (« Export csv de N dossier(s) par l'utilisateur <id> »), sans aucune donnée personnelle.
- **Interface** : boutons « Exporter CSV » et « Exporter PDF » en haut du tableau de bord ; ils reprennent les filtres affichés, indiquent « Préparation… » pendant le téléchargement et montrent une erreur claire en cas d'échec. Un texte rappelle que l'export contient tous les dossiers correspondants et aucune coordonnée.
- **Hors périmètre respecté** : pas d'export des fichiers déposés.
- **Vérifié** : `pytest` (316 verts : accès protégé, colonnes, filtres, brouillons exclus, absence de coordonnées, injection de formule, PDF valide y compris vide et sur plusieurs pages, paramètres invalides, journal) ; serveur lancé : CSV et PDF téléchargés avec un jeton admin ; `tsc -b`, `oxlint`, `vite build` ; page admin vue dans Chrome à 1280 px. **Non vu** : le rendu visuel du PDF (Chrome sans fenêtre n'affiche pas les PDF), l'ouverture du CSV dans Excel, le téléchargement réel par clic dans un navigateur.
