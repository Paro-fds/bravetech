**Statut :** ✅ Done

## En tant que développeur
Je veux que le backend et le frontend soient déployables et accessibles depuis un environnement partagé (serveur Linux faculté / Proxmox)
Afin que l'équipe et les premiers testeurs puissent valider le portail sans dépendre d'une machine de développement individuelle.

## Contexte

US-001 et US-002 ont livré un portail fonctionnel (API + SPA React/Tailwind). Cette story connecte l'environnement de déploiement cible.

L'architecture de déploiement a été arrêtée et enregistrée dans `SOLUTION_DESIGN.md §14` (**ADR-006**) :
- Conteneurisation via Docker et Docker Compose
- Base relationnelle PostgreSQL 15 avec persistance par volume
- Backend FastAPI conteneurisé (Python 3.11-slim)
- Frontend React SPA servi par un serveur web Nginx (multi-stage build) assurant également le reverse-proxying des requêtes `/api/` vers le backend
- Configuration externe via `.env.example` sans aucun secret commité

## Critères d'acceptation

- [x] Le backend FastAPI répond à `GET /api/v1/cursus` depuis le conteneur applicatif
- [x] Le frontend est servi par Nginx avec routage SPA et reverse proxy `/api/`
