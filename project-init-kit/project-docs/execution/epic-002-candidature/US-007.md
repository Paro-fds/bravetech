# US-007: Téléversement sécurisé des pièces requises

**Status:** 🔲 Backlog  
**Milestone:** Epic 2 — Candidature & Suivi  
**GitHub Issue:** [#7](https://github.com/Paro-fds/bravetech/issues/7)  
**Depends on:** US-005, US-006

---

## En tant que candidat
Je veux téléverser mes pièces justificatives au format PDF, JPG ou PNG avec contrôle immédiat de conformité  
Afin que mon dossier d'admission contienne tous les documents officiels exigés par la faculté.

## Contexte
Chaque cursus exige une liste précise de pièces (définies dans `cursus/*.json`, ex: Acte de naissance, Diplôme Bac, Relevé de notes, Photo d'identité, Attestation MPC). Cette story réalise l'étape 3 du tunnel : chaque document requis dispose d'une zone de dépôt dédiée, avec vérification stricte de la taille (≤ 5 Mo) et du type de fichier (contrôle MIME et magic bytes pour rejeter tout exécutable malveillant). Les fichiers sont persistés de manière sécurisée (volume local persistant ou Cloudinary selon configuration).

## Critères d'acceptation
- [ ] L'écran affiche la liste dynamique des pièces requises correspondant au cursus choisi à l'étape 1.
- [ ] Chaque pièce dispose d'une zone de téléversement (drag & drop ou sélecteur de fichier mobile) avec son libellé et son statut (Manquant / Téléversé).
- [ ] La taille de chaque fichier est strictement limitée à **5 Mo maximum** (rejet côté client et côté serveur avec message explicite si dépassé).
- [ ] Les formats acceptés sont limités aux extensions `.pdf`, `.jpg`, `.jpeg`, `.png`.
- [ ] Le serveur vérifie les **magic bytes** du fichier téléversé pour empêcher l'upload d'exécutables déguisés.
- [ ] Une jauge de progression ou un aperçu miniature indique la réussite du téléversement.
- [ ] Le passage à l'étape suivante est conditionné au téléversement de toutes les pièces obligatoires.

## Hors périmètre
- La visionneuse de documents pour le secrétariat et l'évaluation admin (Epic 3 — US-014).
- Le remplacement d'un document suite à un rejet d'évaluation (Epic 3 — US-017).

## Tâches
- [ ] Créer le port d'abstraction `IFileStorage` et son implémentation `LocalFileStorage` (avec support Cloudinary si variables d'environnement configurées)
- [ ] Développer la validation par magic bytes dans `backend/bll/services/file_validator.py`
- [ ] Exposer l'endpoint API `POST /api/v1/candidatures/upload-document`
- [ ] Développer le composant React de zone de téléversement avec retour visuel d'état
- [ ] Écrire les tests unitaires sur la validation de taille et de magic bytes

## Définition de fini
- [ ] Le candidat peut déposer ses fichiers depuis un navigateur mobile, les fichiers invalides (fichiers `.exe` renommés ou > 5 Mo) sont rejetés avec un message clair, et les fichiers valides sont confirmés.
